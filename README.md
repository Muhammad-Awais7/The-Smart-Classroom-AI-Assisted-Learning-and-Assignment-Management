# Smart Classroom – AI-Assisted Learning & Assignment Management System

A comprehensive web-based platform for programming education featuring integrated code execution, AI-powered plagiarism detection, automated feedback, and real-time analytics.

## 🎯 Key Features

- **Code Execution**: Sandbox environment (Python, C, C++, Java)
- **AI Plagiarism Detection**: Text & code similarity with scoring
- **Automated AI Feedback**: Google Gemini API integration
- **Assignment Management**: Submit, track, deadline enforcement
- **Analytics Dashboard**: Performance graphs & charts
- **Discussion Forum**: Real-time communication
- **Role-Based Access**: Admin, Teacher, Student dashboards

## 🛠️ Technologies

- **Frontend**: React.js (Vite), Bootstrap 5, Framer Motion
- **Backend**: Firebase Authentication, Firestore
- **AI**: Google Gemini API
- **Storage**: Cloudinary
- **Version Control**: GitHub

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Set up .env file with Firebase & Gemini API keys

# Run development server
npm run dev
```

Visit `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```
